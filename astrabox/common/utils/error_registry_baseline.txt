# Error codes that reach the wire with no registry row.
#
# `error_spec` answers these with category="unregistered", owner="unknown" —
# honest, and useless to a caller deciding what to do. This file is the arrears
# that predate the gate, not a list of codes that may stay unregistered.
#
# It only shrinks. `scripts/check_error_registry.py` fails when a code here is
# registered and the line is still present, and when a line names a code nothing
# raises any more. Register a code and delete its line in the same commit.
#
# The burn-down order is in docs/maintainers/error-code-registry-gate.md.
